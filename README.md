# Education

Free, open-source learning games for kids. They run offline on Mac and Windows: install, pick a player name, play.

Each game lives in its own folder:

| Folder | For | What it is |
| --- | --- | --- |
| [`dinogarten/`](dinogarten/) | Kindergarten | Walk a little T. rex around a dinosaur world and learn letters and numbers from the dinosaurs you meet. |

The code is MIT licensed. Art and audio credits are listed in each game's folder.
